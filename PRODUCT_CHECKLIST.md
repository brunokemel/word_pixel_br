# World Pixel — checklist de produto

Este arquivo reúne as funcionalidades e serviços planejados para o produto. Marque cada item conforme ele for concluído:

- `[ ]` pendente
- `[x]` concluído

## MVP — base para lançamento

- [ ] Integrar backend real (Supabase ou serviço equivalente)
- [ ] Persistir pixels, usuários, créditos e áreas protegidas
- [ ] Implementar autenticação real
- [ ] Sincronizar alterações do mapa em tempo real
- [ ] Criar sistema de tinta com limite e recarga diária
- [ ] Permitir compra e uso de créditos
- [ ] Oferecer proteção de áreas por 24 horas, 7 dias e 30 dias
- [ ] Criar moderação básica e sistema de denúncias
- [ ] Proteger a aplicação contra bots, spam e abuso
- [ ] Criar páginas compartilháveis para obras e regiões
- [ ] Contratar um provedor de mapas adequado para produção

## Experiência e conteúdo

- [ ] Permitir adicionar título e descrição a uma criação
- [ ] Exibir autor, data e localização de cada criação
- [ ] Criar uma camada de histórias sobre as obras
- [ ] Mostrar o histórico de alterações de pixels e regiões
- [ ] Criar replay da evolução do mapa
- [ ] Arquivar edições e eventos anteriores do mapa
